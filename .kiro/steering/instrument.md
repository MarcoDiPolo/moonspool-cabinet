# Moonspool Cabinet

Build an original offline paper-roll instrument inspired by Marc's dark witchcraft and starry-sky direction. The cabinet resurrects a mechanical player-piano roll as an instrument anyone can punch in a browser. The five pitches form a minor pentatonic scale. Small mistakes should be easy to undo.

Use sixteen equal sixteenth-note positions and five rows with ascending MIDI notes 57, 60, 62, 64 and 67. Each column is a five-bit chord mask. Play the roll at 60–150 quarter notes per minute. Editing and playback must work without a service, account, external font or sound sample. Use original example phrases.

A shared link must reproduce every hole and the tempo. Malformed tokens should leave the roll usable. A downloaded Standard MIDI File must import into a regular workstation as one bar in 4/4, preserving rests, simultaneous pitches, pitch-off events, tempo and the final tick. All exported content contains only musical data supplied to the editor.

Keep the visual language tactile. Warm brass, dark wood, ivory paper, constellations and a moving playhead express the mechanism. The dark palette must keep the keyboard focus and holes visible. Controls must work with a pointer and a keyboard.
